# Урок 4. Основы ООП: классы и объекты

## Цель урока
Понять, что такое объектно-ориентированное программирование, научиться создавать собственные классы, объекты и использовать инкапсуляцию.

---

## Теория

### 1. Что такое ООП?
Объектно-ориентированное программирование (ООП) — это подход, при котором программа строится из взаимодействующих объектов. 
Объект — это конкретная сущность (например, конкретная книга или конкретный пользователь). 
Класс — это чертеж, по которому создаются объекты.

### 2. Создание класса
Класс описывает, какие у объекта будут данные (поля) и действия (методы).
~~~java
public class Book {
    // Поля (характеристики)
    String title;
    String author;
    int year;

    // Метод (действие)
    public void printInfo() {
        System.out.println(title + " (" + author + ", " + year + ")");
    }
}
~~~
### 3. Создание объекта
Чтобы создать объект (экземпляр класса), используется ключевое слово `new`.
~~~java
public class Main {
    public static void main(String[] args) {
        Book myBook = new Book(); // Создали объект
        myBook.title = "Война и мир";
        myBook.author = "Лев Толстой";
        myBook.year = 1869;

        myBook.printInfo(); // Вызов метода объекта
    }
}
~~~

### 4. Как классы связаны между собой
В реальной программе код редко пишется в одном файле. Обычно каждый класс лежит в своем файле.
* Класс `Book` лежит в файле `Book.java`.
* Класс, который запускает программу (с методом `main`), лежит в файле `MainOOP.java`.

Чтобы они «видели» друг друга, в начале каждого файла пишется пакет: `package lesson04;`. Это говорит Java, что файлы лежат в одной папке.

**Важно:** файл с классом, в котором нет метода `main`, нельзя запустить отдельно (зеленая стрелка появится только в файле с `main`). Он используется как «чертеж» для других файлов.

### 5. Конструкторы
Конструктор — это специальный метод, который вызывается при создании объекта (`new`). Он нужен для начальной настройки полей.
Имя конструктора совпадает с именем класса, и он не имеет возвращаемого типа.
~~~java
public class Book {
    String title;
    String author;
    int year;

    // Конструктор
    public Book(String title, String author, int year) {
        this.title = title;
        this.author = author;
        this.year = year;
    }

    public void printInfo() {
        System.out.println(title + " (" + author + ", " + year + ")");
    }
}
~~~
Теперь объект создается так:
    Book myBook = new Book("Война и мир", "Лев Толстой", 1869);

*Ключевое слово `this` используется для обращения к полям текущего объекта. Оно помогает различить поле класса и параметр метода, если у них одинаковые имена.*

### 6. Инкапсуляция и модификаторы доступа
Инкапсуляция — это скрытие внутренней реализации объекта. Мы не даем напрямую менять поля, чтобы защитить данные от некорректных значений.
* `public` — доступно всем.
* `private` — доступно только внутри этого класса.

Чтобы скрыть поля, мы делаем их `private`, а для доступа создаем специальные методы: **геттеры** (получить значение) и **сеттеры** (установить значение).
~~~java
public class Book {
    private String title;
    private String author;
    private int year;

    public Book(String title, String author, int year) {
        this.title = title;
        this.author = author;
        this.year = year;
    }

    // Геттер для title
    public String getTitle() {
        return title;
    }

    // Сеттер для year с проверкой
    public void setYear(int year) {
        if (year > 0) {
            this.year = year;
        } else {
            System.out.println("Ошибка: год не может быть отрицательным");
        }
    }

    public void printInfo() {
        System.out.println(title + " (" + author + ", " + year + ")");
    }
}
~~~
### 7. Метод toString()
Метод `toString()` возвращает строковое представление объекта. Если его переопределить, можно красиво выводить объект в консоль.
~~~java
@Override
public String toString() {
    return "Book{" + "title='" + title + '\'' + ", year=" + year + '}';
}

//Теперь можно писать:
System.out.println(myBook); // Выведет: Book{title='Война и мир', year=1869}
~~~
