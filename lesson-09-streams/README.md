# Урок 9. Stream API

## Цель урока
Научиться обрабатывать коллекции данных в функциональном стиле с помощью Stream API: фильтровать, преобразовывать, сортировать и собирать результаты.

---

## Теория

### 1. Что такое Stream?
Stream (поток) — это последовательность элементов, которую можно обрабатывать декларативно (описывая, *что* сделать, а не *как*).
Поток не хранит данные, он их обрабатывает.

Важно: коллекция (`List`, `Set`) — это хранилище, а `Stream` — это «конвейер» для обработки.

### 2. Создание стрима
Стрим можно получить из любой коллекции с помощью метода `.stream()`.

~~~java
List<String> names = List.of("Иван", "Мария", "Петр");
Stream<String> stream = names.stream();
~~~

### 3. Промежуточные операции
Это методы, которые преобразуют поток и возвращают новый поток. Они **ленивы** — выполняются только тогда, когда вызывается терминальная операция.

* `filter(Predicate)` — оставляет только элементы, удовлетворяющие условию.
* `map(Function)` — преобразует каждый элемент.
* `sorted()` — сортирует элементы.
* `distinct()` — убирает дубликаты.
* `limit(n)` — ограничивает количество элементов.
* `skip(n)` — пропускает первые n элементов.

Пример:
~~~java
List<String> names = List.of("Иван", "Мария", "Петр", "Анна");

names.stream()
     .filter(name -> name.startsWith("А")) // Оставить только на "А"
     .map(String::toUpperCase)             // Преобразовать в верхний регистр
     .forEach(System.out::println);        // Вывести
// Выведет: АННА
~~~

### 4. Терминальные операции
Это методы, которые запускают обработку потока и возвращают результат (или ничего не возвращают).
После терминальной операции поток считается использованным, его нельзя переиспользовать.

* `forEach(Consumer)` — выполняет действие для каждого элемента.
* `collect(Collectors.toList())` — собирает элементы в список.
* `count()` — возвращает количество элементов.
* `reduce()` — сворачивает все элементы в одно значение.
* `anyMatch(Predicate)` — проверяет, есть ли хотя бы один элемент, удовлетворяющий условию.
* `allMatch(Predicate)` — проверяет, все ли элементы удовлетворяют условию.

Пример:
~~~java
List<Integer> numbers = List.of(1, 2, 3, 4, 5);

// Собрать четные числа в новый список
List<Integer> evenNumbers = numbers.stream()
                                   .filter(n -> n % 2 == 0)
                                   .collect(Collectors.toList());
System.out.println(evenNumbers); // [2, 4]
~~~

### 5. Группировка (Collectors.groupingBy)
Мощная операция, которая позволяет сгруппировать элементы по какому-либо признаку.

~~~java
List<String> names = List.of("Иван", "Мария", "Петр", "Анна");

Map<Integer, List<String>> byLength = names.stream()
    .collect(Collectors.groupingBy(String::length));
// {4=[Иван, Петр, Анна], 5=[Мария]}
~~~
