## Требования для запуска

* **JDK:** 17 или выше (рекомендуется LTS-версия: 21 или 25).
* **Среда разработки:** IntelliJ IDEA Community Edition (рекомендуется) или любая другая IDE.
* **Git:** для контроля версий.

---

## Структура репозитория

* `lesson-XX-название/` — папки с теоретическим материалом для каждого урока.
    * `README.md` — теория, разбор кода и чек-лист.
    * `TASKS.md` — практические задания с готовыми решениями для сверки.
* `src/` — исходный код примеров.
    * `lessonXX/` — папки с примерами кода для каждого урока.

---

## 🚀 Как проходить курс

1. Читаем теорию в `README.md` текущего урока.
2. Запускаем примеры кода из соответствующей папки в `src/`.
3. Пробуем решить задания из `TASKS.md` самостоятельно.
4. Сверяемся с решением в `TASKS.md`, если возникают трудности.
5. Делаем коммит после каждого пройденного урока.
