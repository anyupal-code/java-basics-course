## Теория

### 1. JDK, JRE и JVM — в чём разница?
* **JVM (Java Virtual Machine)** — «виртуальный компьютер», который выполняет байт-код. Благодаря ей Java работает на любой ОС (принцип «Write Once, Run Anywhere»).
* **JRE (Java Runtime Environment)** — среда для *запуска* программ (JVM + стандартные библиотеки). Нужна пользователям.
* **JDK (Java Development Kit)** — инструменты для *разработчика* (компилятор `javac`, JVM, библиотеки). Нужен нам.

### 2. Как код превращается в программу
1. Вы пишете файл `Main.java`.
2. Компилятор превращает его в `Main.class` (байт-код — понятный JVM).
3. JVM читает байт-код и выполняет его.

### 3. Структура проекта в IDEA
В левой панели вы видите:
* `src` — папка с исходным кодом (здесь мы пишем).
* `out` — папка, куда IDEA автоматически складывает скомпилированные `.class` файлы (туда лезть не нужно).

### 4. Анатомия программы
~~~java
public class Main {
    public static void main(String[] args) {
        System.out.println("Привет, мир!");
    }
}
~~~
* **`public class Main`** — объявление класса. В Java весь код живёт внутри классов. Имя класса должно совпадать с именем файла (`Main.java`).
* **`public static void main(String[] args)`** — точка входа. JVM ищет именно этот метод, чтобы начать выполнение.
  * `public` — доступно всем;
  * `static` — работает без создания объекта;
  * `void` — ничего не возвращает;
  * `String[] args` — массив аргументов командной строки.
* **`System.out.println()`** — вывод текста в консоль с новой строки.

**Современная опция (Java 25+):**
Начиная с Java 25, для простых учебных программ сигнатуру метода `main` можно упростить, убрав `public`, `static` и `String[] args`:
~~~java
void main() {
    System.out.println("Привет, мир!");
}
~~~
Это работает только в простых файлах (без пакетов) и сделано для удобства новичков. В реальных проектах и классических учебниках вы всё ещё встретите полную сигнатуру `public static void main(String[] args)` — она универсальна.

### 5. Вывод текста и спецсимволы
* `System.out.print()` — выводит текст **без** переноса на новую строку.
* `System.out.println()` — выводит текст **с** переносом.
* **Спецсимволы** (работают внутри строк):
  * `\n` — перенос на новую строку;
  * `\t` — табуляция (отступ);
  * `\"` — кавычка внутри строки;
  * `\\` — обратный слэш.

### 6. Комментарии
* `//` — однострочный комментарий (до конца строки).
* `/* ... */` — многострочный комментарий.
Компилятор их игнорирует, они нужны для людей.

### 7. Как читать ошибки компилятора
Если код подчеркнут красным, внизу в панели `Build` появится сообщение об ошибке.
* `';' expected` — забыли точку с запятой.
* `Cannot resolve symbol 'String'` — опечатка в имени (например, написали `string` с маленькой буквы).
* Ошибка всегда указывает на строку, где компилятор «споткнулся».
