# Урок 2. Переменные, типы данных и ввод-вывод

## Цель урока
Научиться хранить данные в переменных, понимать разницу между примитивными типами и ссылочными, а также научиться получать данные от пользователя через консоль.

---

## Теория

### 1. Что такое переменная
Переменная — это именованная область в памяти, в которой хранится значение. В Java у каждой переменной есть строгий тип.

Синтаксис:
    тип имяПеременной = значение;

Пример:
    int age = 25;
    String name = "Иван";

### 2. Примитивные типы данных
В Java 8 примитивных типов. В курсе нам понадобятся четыре основных:
* `int` — целые числа (например, 42, -10). Занимает 4 байта.
* `double` — числа с плавающей точкой (например, 3.14). Занимает 8 байт.
* `boolean` — логический тип. Принимает только `true` или `false`.
* `char` — один символ (например, 'A', '5'). Пишется в одинарных кавычках.

*Примечание:* для больших целых чисел используется `long` (8 байт), но на начальном этапе хватит `int`.

### 3. Ссылочные типы и String
`String` — это не примитив, а класс (ссылочный тип). Он используется для хранения текста.
Строки пишутся в двойных кавычках:
    String greeting = "Привет!";

### 4. Правила именования (конвенции)
* Имя начинается с маленькой буквы (например, `userName`).
* Используется camelCase (если слов несколько, каждое следующее с большой буквы).
* Нельзя использовать пробелы и спецсимволы (разрешены только буквы, цифры, `_` и `$`).
* Имя не должно начинаться с цифры.
* Нельзя использовать зарезервированные слова (например, `class`, `int`, `public`).

### 5. Константы
Если значение не должно меняться, используется ключевое слово `final`.
    final double PI = 3.14159;
Попытка изменить константу вызовет ошибку компиляции.

### 6. Ввод с клавиатуры
Для получения данных от пользователя используется класс `Scanner` из пакета `java.util`.
~~~java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        
        System.out.print("Введите ваш возраст: ");
        int age = scanner.nextInt();
        
        System.out.println("Ваш возраст: " + age);
        
        scanner.close(); // Закрываем сканнер
    }
}
~~~
Методы `Scanner`:
* `nextInt()` — читает целое число.
* `nextDouble()` — читает число с плавающей точкой.
* `nextLine()` — читает строку целиком (включая пробелы).
* `next()` — читает одно слово (до пробела).

**Важный нюанс:** после `nextInt()` или `nextDouble()` в буфере остается символ новой строки. Если сразу после этого вызвать `nextLine()`, он прочитает пустую строку. Решение: добавить дополнительный `scanner.nextLine()` для очистки буфера.

### 7. Преобразование типов
* **Автоматическое (расширяющее):** меньшее по размеру значение помещается в больший тип.
      int a = 10;
      double b = a; // 10.0
* **Явное (сужение):** большее значение в меньший тип. Требует указания типа в скобках.
      double d = 10.99;
      int i = (int) d; // 10 (дробная часть отбрасывается)
