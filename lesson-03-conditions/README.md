# Урок 3. Условия, циклы и массивы

## Цель урока
Научиться управлять ходом выполнения программы с помощью условий и циклов, а также освоить работу с массивами для хранения наборов данных.

---

## Теория

### 1. Условный оператор if-else
Позволяет выполнять код только при определенном условии.
~~~java
int age = 18;
if (age >= 18) {
    System.out.println("Доступ разрешен");
} else {
    System.out.println("Доступ запрещен");
}
~~~
* `if` — проверяет условие. Если оно `true`, выполняется блок кода внутри фигурных скобок.
* `else` — выполняется, если условие оказалось `false`.
* `else if` — позволяет проверить несколько условий последовательно.
~~~java
int score = 85;
if (score >= 90) {
    System.out.println("Отлично");
} else if (score >= 70) {
    System.out.println("Хорошо");
} else {
    System.out.println("Нужно подтянуть");
}
~~~
### 2. Логические операторы
Используются для объединения условий.
* `&&` (И) — истинно, если оба условия истинны.
* `||` (ИЛИ) — истинно, если хотя бы одно условие истинно.
* `!` (НЕ) — инвертирует значение (из `true` делает `false`).
~~~java
boolean isWeekend = true;
boolean isHoliday = false;

if (isWeekend || isHoliday) {
    System.out.println("Отдыхаем!");
}
~~~
### 3. Оператор switch
Удобен, когда нужно сравнить одну переменную с множеством значений.
~~~java
int day = 3;
switch (day) {
    case 1:
        System.out.println("Понедельник");
        break;
    case 2:
        System.out.println("Вторник");
        break;
    default:
        System.out.println("Другой день");
}
~~~
* `break` — прерывает выполнение `switch` (иначе код "провалится" в следующий `case`).
* `default` — выполняется, если ни один `case` не совпал.

### 4. Циклы
* **Цикл `for`** — используется, когда известно количество итераций.
~~~java
for (int i = 1; i <= 5; i++) {
    System.out.println("Итерация: " + i);
}
~~~
* **Цикл `while`** — выполняется, пока условие истинно.
~~~java
int i = 1;
while (i <= 5) {
    System.out.println("Итерация: " + i);
    i++;
}
~~~
* **Цикл `do-while`** — гарантированно выполнится хотя бы один раз, даже если условие изначально ложно.
~~~java
int j = 10;
do {
    System.out.println("Это выполнится один раз");
} while (j < 5);
~~~
### 5. Массивы
Массив — это структура данных, хранящая набор элементов одного типа.
Длина массива задается при создании и не может быть изменена.
~~~java
int[] numbers = new int[5]; // Массив из 5 целых чисел (по умолчанию нули)
numbers[0] = 10;
numbers[1] = 20;
~~~
// Либо сразу с инициализацией:
~~~java
int[] primes = {2, 3, 5, 7, 11};
String[] names = {"Иван", "Мария", "Петр"};
~~~
* Индексация начинается с нуля. Первый элемент: `array[0]`. Последний: `array[array.length - 1]`.
* `array.length` — свойство, возвращающее длину массива (без скобок).

### 6. Цикл for-each (для массивов)
Упрощенный вариант цикла `for` для перебора всех элементов массива.
~~~java
String[] names = {"Иван", "Мария", "Петр"};
for (String name : names) {
    System.out.println(name);
}
~~~
