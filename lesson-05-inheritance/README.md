# Урок 5. Наследование, полиморфизм и интерфейсы

## Цель урока
Понять, как переиспользовать код с помощью наследования, научиться работать с полиморфизмом и создавать контракты с помощью интерфейсов.

---

## Теория

### 1. Наследование
Наследование позволяет создать новый класс на основе существующего, перенимая его поля и методы. Это помогает избежать дублирования кода.
* **Родительский класс** (суперкласс) — класс, от которого наследуются.
* **Дочерний класс** (подкласс) — класс, который наследует.

Для наследования используется ключевое слово `extends`.

~~~java
// Родительский класс
public class Animal {
    protected String name;

    public Animal(String name) {
        this.name = name;
    }

    public void eat() {
        System.out.println(name + " ест.");
    }
}

// Дочерний класс
public class Dog extends Animal {
    public Dog(String name) {
        super(name); // Вызов конструктора родителя
    }

    public void bark() {
        System.out.println(name + " гавкает.");
    }
}
~~~

* `protected` — модификатор доступа, который делает поле доступным внутри класса, его подклассов и в том же пакете.
* `super` — используется для вызова методов или конструктора родительского класса.

### 2. Переопределение методов (@Override)
Дочерний класс может изменить поведение метода родителя. Это называется переопределением.
Для проверки правильности переопределения используется аннотация `@Override`.

~~~java
public class Cat extends Animal {
    public Cat(String name) {
        super(name);
    }

    @Override
    public void eat() {
        System.out.println(name + " ест рыбу.");
    }
}
~~~

### 3. Полиморфизм
Полиморфизм — это способность объектов с одинаковым интерфейсом (родительским классом) иметь разную реализацию.
Это позволяет работать с разными типами объектов через ссылку на общий тип.

~~~java
Animal myDog = new Dog("Шарик");
Animal myCat = new Cat("Мурка");

myDog.eat(); // Шарик ест.
myCat.eat(); // Мурка ест рыбу.
~~~

*Несмотря на то, что переменные типа `Animal`, Java во время выполнения определяет, какой именно метод вызвать (из `Dog` или `Cat`).*

### 4. Абстрактные классы
Абстрактный класс — это класс, который нельзя создать напрямую (нельзя написать `new Animal()`). Он служит базой для других классов.
Он может содержать абстрактные методы (без реализации), которые обязаны реализовать дочерние классы.

~~~java
public abstract class Animal {
    protected String name;

    public Animal(String name) {
        this.name = name;
    }

    // Абстрактный метод (без тела)
    public abstract void makeSound();
}
~~~

### 5. Интерфейсы
Интерфейс — это «контракт», который класс обязуется выполнить. В интерфейсе только объявляются методы (без реализации).
Класс может реализовать несколько интерфейсов (в отличие от наследования, где родитель только один).

~~~java
public interface Swimmable {
    void swim();
}

public class Duck extends Animal implements Swimmable {
    public Duck(String name) {
        super(name);
    }

    @Override
    public void makeSound() {
        System.out.println(name + " крякает.");
    }

    @Override
    public void swim() {
        System.out.println(name + " плывет.");
    }
}
~~~
