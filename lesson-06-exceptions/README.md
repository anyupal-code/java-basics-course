# Урок 6. Исключения и обработка ошибок

## Цель урока
Научиться предвидеть и обрабатывать ошибки, чтобы программа не «падала» при некорректных данных, а также создавать собственные исключения.

---

## Теория

### 1. Что такое исключение
Исключение (Exception) — это событие, которое возникает во время выполнения программы и нарушает её нормальный ход.
Если исключение не обработать, программа аварийно завершится (вы увидите красный текст в консоли).

Примеры:
* Деление на ноль (`ArithmeticException`).
* Выход за границы массива (`ArrayIndexOutOfBoundsException`).
* Попытка ввести букву вместо числа (`InputMismatchException`).

### 2. Конструкция try-catch
Чтобы программа не падала, опасный код оборачивают в блок `try`, а обработку ошибки пишут в `catch`.

~~~java
try {
    int result = 10 / 0;
} catch (ArithmeticException e) {
    System.out.println("Ошибка: деление на ноль!");
}
~~~

* В `try` — код, который может вызвать ошибку.
* В `catch` — что делать, если ошибка произошла.
* Переменная `e` содержит информацию об ошибке (например, сообщение).

### 3. Блок finally
Блок `finally` выполняется всегда (и при ошибке, и без неё). Обычно там закрывают ресурсы (файлы, соединения с базой данных).

~~~java
try {
    System.out.println("Работаем...");
} catch (Exception e) {
    System.out.println("Ошибка!");
} finally {
    System.out.println("Этот код выполнится в любом случае.");
}
~~~

### 4. Checked и Unchecked исключения
* **Unchecked** (наследники `RuntimeException`) — компилятор не заставляет их обрабатывать. Пример: `ArithmeticException`.
* **Checked** (все остальные) — компилятор **требует** обработать их (в `try-catch` или пробросить дальше). Пример: `IOException` (работа с файлами).

### 5. Свои исключения
Вы можете создавать собственные исключения для конкретных ситуаций в программе.
Обычно они наследуются от `Exception` или `RuntimeException`.

~~~java
public class InvalidAgeException extends Exception {
    public InvalidAgeException(String message) {
        super(message);
    }
}
~~~

Теперь это исключение можно использовать в коде:

~~~java
public void checkAge(int age) throws InvalidAgeException {
    if (age < 0 || age > 120) {
        throw new InvalidAgeException("Некорректный возраст: " + age);
    }
}
~~~

* Ключевое слово `throw` используется, чтобы «выбросить» исключение.
* Ключевое слово `throws` в сигнатуре метода предупреждает, что этот метод может выбросить данное исключение.
